BOOM-project

The goal of this project is to allow current and former students to leave testimonials that prospective students can read.

Stretch Goals:

- As a potential buyer of a product, I want to be able to purchase a product.
- As a buyer of a product, I want to be able to view a record of purchases I have made.
- As a seller of a product, I want to be able to view a record of sales of my products.
